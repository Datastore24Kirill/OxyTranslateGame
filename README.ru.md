# OxyTranslateGame

**Перевод игр для Mac и Windows — готовое приложение, без ручной сборки.**

## Скачать

Откройте [Releases](https://github.com/Datastore24Kirill/OxyTranslateGame/releases):

- **Mac:** скачайте ZIP для своего процессора, распакуйте и перенесите `.app` в «Программы».
- **Windows:** скачайте файл `Windows-x64-Setup.exe` и установите. Есть и Portable ZIP.

Требуется macOS 14+ или Windows 10/11 x64. Сборки тестовые, без платной подписи Apple/Microsoft. Предупреждения системы возможны; открывайте только сборки, которым доверяете, и не отключайте защиту ОС целиком.

## Версия 0.3: языки и профили игр

![Переключение языка и темы](docs/v03-demo.gif)

- Интерфейс: **системный / русский / English**, смена без перезапуска.
- Исходный язык и язык перевода выбираются отдельно; есть обмен местами и осторожное автоопределение.
- Три режима: быстрый Argos, литературный Ollama и ближе к оригиналу Ollama.
- Профили игр: языки, модель, словарь, до восьми областей, тема, шрифт, прозрачность и горячие клавиши. Импорт и экспорт JSON.
- Слежение за несколькими областями, привязка к окну на текущем экране, пауза при сворачивании.
- Окно перевода: поверх игры, компактный вид, пропуск кликов, оригинал. Вернуть управление можно из меню в трее.
- История с поиском, лимитом и CSV. Сохранение на диск выключено по умолчанию.
- Каталог прямых языковых пар, загрузка и удаление моделей, настройка горячих клавиш, экономичный режим.
- Проверка и исправление OCR, увеличение мелкого текста, повышение контраста, предпросмотр снимка только в памяти.
- Мастер первого запуска и технический отчёт без диалогов и снимков по умолчанию.

[Полное описание и ограничения](docs/features-0.3.md). Сборка 0.3 публикуется как предварительная до проверки новых функций в реальных играх.

## Быстрый старт

1. Выберите язык интерфейса в **Настройках**, а язык игры и язык перевода — на главном экране.
2. Откройте **Модели → Проверить модели**, выберите доступную пару и скачайте офлайн-модель. Размер зависит от пары. Для литературного режима отдельно установите Ollama.
3. Нажмите **Выбрать область**. На Mac подтвердите запрос записи экрана и перезапустите приложение, если этого требует система.
4. Выделите неподвижный диалог. Перевод появится в отдельном окне.
5. Включите **Автоматически следить за репликами**. Для нескольких областей включите последовательное слежение. Привязка к окну действует в текущем сеансе; после перехода на другой монитор выберите область заново.
6. Если распознавание ошиблось, нажмите **Проверить оригинал**, исправьте текст и переведите снова. OCR проверено на английском; выбор другого языка перевода не гарантирует распознавание всех алфавитов.

## Литературный перевод

Быстрый режим использует компактную модель Argos. Для более естественной речи есть **«Литературный · Ollama»**: он учитывает три предыдущие реплики и словарь имён.

1. Установите и запустите бесплатную [Ollama](https://ollama.com/download).
2. В разделе «Модели» скачайте `qwen3:4b` или `qwen3:8b` кнопкой приложения.
3. Выберите литературный режим. Большая модель требует нескольких гигабайт на диске и больше памяти; на слабом компьютере перевод может быть медленным.
4. Добавьте имена во вкладке **«Имена и термины»**: `Mrs. Smith = миссис Смит`.

Это локальная модель, не подписка и не платный API. Более литературный стиль не означает безошибочный перевод. Словарь применяется только в литературном режиме.

## Google и Яндекс

Кнопки **Google ↗** и **Яндекс ↗** открывают распознанный текст на сайте переводчика после отдельного подтверждения. Это бесплатный браузерный вариант, а не скрытый облачный API. Автоматический перевод внутри программы работает локально. Официальные облачные API этих компаний имеют отдельные условия, квоты и биллинг.

## Данные

По умолчанию снимки и диалоги остаются в памяти. Сохранение истории на диск включается отдельно; отключение удаляет локальный файл истории. Профили, модели и сохранённые словари хранятся локально. CSV, JSON профиля и технический ZIP создаются только по вашему запросу. Текст и снимок добавляются в технический отчёт только через отдельные флажки. Литературный режим общается с Ollama на этом же компьютере. Онлайн-кнопки передают только текст выбранному сервису, не изображение.

Мелкий шрифт, анимация, защищённый контент и некоторые полноэкранные игры могут мешать распознаванию. Попробуйте оконный режим. На Mac после обновления тестовой сборки иногда нужно заново выдать доступ к экрану.

Полная документация и инструкции **для разработчиков**: [README](README.md). Обычным пользователям собирать приложение не нужно.

## Обновления и разрешения macOS

Проверка новых готовых релизов выполняется при запуске и раз в 6 часов. Есть ручная проверка, «Позже», пропуск версии и отключение автопроверки. Кнопка «Обновить» после подтверждения скачивает сборку для вашей системы, сверяет SHA-256 с метаданными GitHub, заменяет приложение и перезапускает его. Предыдущая копия сохраняется рядом с установленным приложением для восстановления. Модели и настройки остаются в папке данных. Проверка отправляет GitHub только обычный запрос списка релизов — без диалогов и скриншотов.

Ad-hoc подпись меняется между сборками. Если запись экрана включена, а доступа нет, завершите все копии, удалите старую запись приложения в настройках записи экрана, добавьте используемую копию заново и перезапустите. Используйте одно постоянное расположение приложения. Для сохранения доверия между публичными релизами нужна совместимая постоянная подпись Developer ID; текущие предварительные сборки её не имеют.
