# OxyTranslateGame

Бесплатный перевод выделенной области экрана на Mac. Подходит для диалогов, меню и описаний в разных играх и приложениях.

[Скачать тестовую версию для Mac](https://github.com/Datastore24Kirill/OxyTranslateGame/releases/tag/v0.1.0) — готовая сборка для Apple silicon, macOS 15+.

## Начало работы

Требуется **macOS 15+**. Интерфейс на русском; по умолчанию перевод с английского на русский.

1. Откройте приложение и нажмите **«Доступ к экрану»**. В настройках macOS разрешите запись экрана для OxyTranslateGame. При необходимости перезапустите приложение.
2. Выберите языки и нажмите **«Подготовить языки»**. macOS предложит загрузить модели Apple. После загрузки перевод работает локально.
3. В игре нажмите **⌥⌘T** и выделите мышью нужный текст. Esc отменяет выделение.
4. Перевод появится в отдельном окне поверх игры. Окно можно перемещать, менять размер и включать показ оригинала.
5. Для автоматического перевода субтитров включите **«Следить за областью»**. Новая реплика переводится при следующей проверке (1, 2 или 4 секунды).
6. Кнопка закрытия в окне перевода также останавливает слежение. Esc закрывает окно перевода, когда оно имеет фокус. Настройки и остановка доступны через значок в строке меню.

Альтернативная горячая клавиша — **⇧⌥⌘T**. После перемещения игры или изменения масштаба заново выделите область. Выделение ограничено одним экраном; можно выбрать любой подключённый монитор.

## Установка из исходников

Установите Xcode 16+ и выполните в папке проекта:

```sh
swift test
./scripts/build-app.sh
open dist/OxyTranslateGame.app
```

Готовое приложение можно перенести в «Программы» или на рабочий стол. Python и платный API не нужны. Тестовая сборка не нотарифицирована Apple. Если macOS блокирует скачанную сборку, используйте «Открыть всё равно» в настройках безопасности, только если доверяете исходникам. Не отключайте защиту macOS целиком.

При обновлении локальной сборки разрешение записи экрана иногда требуется выдать заново: удалите старую запись приложения из списка и добавьте новую.

## Приватность и ограничения

Снимки и текст не сохраняются на диск. Обработка выполняется средствами Apple на устройстве; первоначальная загрузка языков требует интернета. Приложение не управляет мышью в игре и не требует «Универсального доступа».

Мелкий шрифт, анимация и защищённый контент могут мешать распознаванию. В отдельных полноэкранных играх понадобится оконный режим. Качество и поддержка языков зависят от Apple. Это первая версия: совместимость со всеми играми не гарантируется.
